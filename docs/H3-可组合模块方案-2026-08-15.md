# H3 FL2V 可组合提示词模块方案

> 日期: 2026-08-15  
> 目标: 旁白/各类辅助模块可按视频类型选配，不强制启用

---

## 设计原则

**每个可选模块 = 一组 Registry Slot 的开关组合**，通过 `H3PromptInput.activeModules` 控制。

```
H3 FL2V Prompt = 基础模块(always) + 可选模块(activeModules)
```

---

## 模块定义

### 基础模块 (always on)

| 层 | 模块 key | 内容 |
|----|---------|------|
| Content | `content_base` | videoScript, characters, frame anchors, episode, audio |
| Constraint | `constraints_time` | 时间分段 |
| Constraint | `constraints_action` | 动作节拍 |
| Constraint | `constraints_camera` | 运镜 |
| Constraint | `constraints_dialogue` | 对白格式 |
| Constraint | `constraints_format` | 输出格式 |
| Constraint | `constraints_no_env` | 环境禁止 |
| Constraint | `constraints_body` | 身体动词语汇 |
| Guide | `guide_base` | system prompt |

### 可选模块

| 模块 key | 适用视频类型 | 新增内容 |
|---------|-------------|---------|
| `narration` | 历史剧、仙侠、叙事类 | Content: narration_hint + narration_inject; Constraint: voice规则; Pipeline: 自动生成旁白 |

未来可扩展:
| `action_intensity` | 战斗/动作类 | 强化动作描述密度、打击感词汇 |
| `comedy_timing` | 喜剧类 | 节奏提示、转场标记 |
| `horror_atmosphere` | 悬疑/恐怖类 | 氛围强化、惊吓节拍 |

## 实现

### types.ts — 扩展 H3PromptInput

```typescript
export interface H3PromptInput {
  // ... existing fields ...
  
  /** Active optional modules (empty = base only). E.g. ["narration"] */
  activeModules?: string[];
}
```

### video-generate.ts — 根据项目配置决定模块

```typescript
// 从 project config 或 env 读取活跃模块
const activeModules: string[] = [];
if (process.env.H3_FL2V_NARRATION !== "off") {
  // 可扩展: 根据 project.videoType 决定
  activeModules.push("narration");
}
```

### fl2v/builder.ts — 条件触发

```typescript
// Phase 2: Auto-generate narration only when module is active
if (input.activeModules?.includes("narration") && !input.dialogues?.length && !input.narrations?.length) {
  // ... generate narration ...
}
```

### fl2v/prompt-template.ts — 条件渲染

```typescript
function buildContentLayer(input, contentSlots, lang) {
  // ...
  
  // Narration hint: only when module is active AND no pre-generated narrations
  if (input.activeModules?.includes("narration") && !input.narrations?.length) {
    const hint = r("narration_hint", "");
    if (hint) parts.push(hint);
  }
  
  // Pre-generated narration: only when present
  if (input.narrations?.length) {
    // ... inject ...
  }
}

function buildConstraintLayer(input, constraintSlots, lang) {
  // ...
  
  // Voice constraint: only when narration module is active
  if (input.activeModules?.includes("narration")) {
    // ... voice rule ...
  }
}
```

### Registry — narration 模块的 Slots 不变

```
video_h3_fl2v_narration (4 slots)     ← narration 模块的专属 Registry entries
video_h3_fl2v_content.narration_hint  ← 通过 activeModules 控制是否渲染
video_h3_fl2v_constraints.voice       ← 通过 activeModules 控制是否渲染
```
